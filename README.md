# SQL Studio

A fast, modern desktop client for **Microsoft SQL Server**, built for Windows.

This repository hosts the **installer and release notes** only.

## Download

👉 **[Download the latest version](https://github.com/FaridMursudov/SqlStudio-releases/releases/latest/download/SqlStudio-Setup.exe)**

Or see all versions and what changed in each: [Releases](https://github.com/FaridMursudov/SqlStudio-releases/releases)

## Install

1. Download `SqlStudio-Setup.exe`.
2. Run it and follow the setup.
3. Start **SQL Studio** from the Start menu.

> Windows may show a SmartScreen warning because the installer is not code-signed.
> Click **More info → Run anyway**.

## Updates

SQL Studio checks for new versions on start.
When one is available, it shows what's new and updates with one click (**Update now**).

## Features

- **Query editor**: syntax highlighting, formatting, multiple result tabs, query history
- **Object Explorer**: tables, views, procedures, functions, types; rename (F2), View References, type-ahead search
- **Compare with...**: compare a table, view, procedure or function with another server or database
  - scripts side by side with highlighted differences
  - tables: columns, indexes and triggers
- **Database Diagrams**: relations between tables, saved diagrams, export to PNG
- Dark and light themes

## Requirements

- Windows 10 / 11 (64-bit)
- Access to a Microsoft SQL Server instance
